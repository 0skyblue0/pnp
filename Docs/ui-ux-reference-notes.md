# UI/UX Reference Notes

- Recorded for current design pass.
- Scope: improve readability and perceived polish without a large design-system rewrite.

## External references checked

- Material Design 3 design tokens: confirms token-led theming, surface/elevation, and state-layer approach.
- Nielsen Norman Group 10 usability heuristics: prioritizes visibility of system status, recognition over recall, consistency, and error prevention.
- WCAG 2.2 Quick Reference: keeps focus states, contrast, touch target size, and readable hierarchy in scope.
- Linear design-system skill template: used only as an external style reference for subtle elevation, soft borders, reduced visual noise, and precise typography.

## Applied direction

- Keep current warm bakery/operations identity instead of replacing it with a new dark or brand system.
- Preserve existing routes, components, DOM hooks, and page hierarchy.
- Improve visual hierarchy with warmer neutral tokens, softer cards, stronger active navigation, clearer focus rings, and more intentional shadows.
- Prefer small global token/component updates over page-by-page rewrites.

## Constraints respected

- No large information architecture change.
- No route/API behavior change.
- No broad component decomposition.
- Allowed changes used: color, shadow, radius, focus ring, subtle nav/header styling, minor component surface treatment.
