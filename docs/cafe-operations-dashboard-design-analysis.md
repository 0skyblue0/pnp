# 카페 운영 관리 대시보드 디자인 시스템·레이아웃 분석

## 분석 기준

- 원본: `Docs/User_Send/카페 운영 관리 대시보드.zip`
- 생성물: `paul&paulina 운영 대시보드.dc.html` (Claude Design HTML)
- 기준 캔버스: **1194 × 834px 이상**, 가로형 태블릿/소형 데스크톱
- 성격: 운영자가 하루 업무와 매출을 빠르게 판단하는, 따뜻한 베이커리 톤의 정보 밀도 높은 B2B 대시보드

원본은 화면별 인라인 스타일로 만들어져 있다. 아래 토큰은 해당 값을 의미 기반으로 정규화한 구현 명세이며, `#26e18`처럼 유효하지 않은 생성물 오타는 토큰에 포함하지 않았다.

## 1. 시각 언어

### 디자인 원칙

1. **짙은 코코아 프레임 + 크림 작업면**: 고정 내비게이션은 매장 브랜드의 안정감을, 본문은 종이 같은 밝은 작업면을 만든다.
2. **골드 한 가지로 행동과 선택 상태를 연결**: 현재 메뉴, 차트의 올해 값, 핵심 일정, 강조 카드에만 사용한다.
3. **카드 안의 작은 데이터 블록**: 화면은 많은 정보를 보여 주지만, 카드·얇은 구분선·일관된 8/12/14px 간격으로 묶는다.
4. **색만으로 상태를 전달하지 않음**: 일정은 배지 텍스트, 증감은 `+/-` 숫자, 경고는 메시지와 아이콘을 함께 둔다.

## 2. 공통 프레임과 컴포넌트

### 앱 셸

```text

┌──────────────────────────────────────────────────────────────┐
│ 210px sidebar │ 984px main                                    │
│               │  header: 좌우 26px, 상단 16px                 │
│               │  tab bar / divider                            │
│               │  content: 좌우 26px, 카드 간격 14px           │
```

- **사이드바**: 폭 210px, `#261e18`, 패딩 `22px 12px 16px`, 세로 flex. 상단 브랜드, 중앙 메뉴, 하단 사용자 카드로 나뉜다.
- **메뉴 행**: 좌우 10px/상하 9px, 반지름 8px, 13.5px. 활성 상태는 골드 배경과 잉크 글자, 비활성은 `#c9bcab` 글자다.
- **사용자 카드**: 하단 고정 성격, 흰색 6% 투명 배경, 반지름 10px. 30px 골드 원형 아바타와 이름·역할을 둔다.
- **본문 헤더**: `#fbf8f3`, 좌우 26px. 좌측은 제목+부제, 우측은 기간 선택·검색·보조 액션·주요 액션을 flex로 배치한다.
- **탭**: 제목 헤더 아래. 활성 탭은 2.5px 골드 하단선과 약한 골드 그라데이션, 비활성 탭은 중성 텍스트다.

### 반응형 전환 규칙

원본은 1194px의 정적 제안이다. 구현 시에는 다음 기준으로 전환한다.

| 폭 | 셸 | 콘텐츠 |
| --- | --- | --- |
| ≥ 1024px | 210px 고정 사이드바 | 원본 그리드 유지 |
| 768–1023px | 72px 아이콘 레일 또는 접이식 메뉴 | 4열 KPI는 2×2, 2열은 유지 가능 |
| < 768px | 상단 메뉴/드로어, 고정 sidebar 제거 | KPI 1열, 카드 1열, 표는 카드형 행 또는 안전한 가로 스크롤 |

모든 클릭 영역은 최소 44×44px, 아이콘 단독 버튼에는 `aria-label`, 색으로만 구분하는 상태에는 글자/아이콘을 추가한다.

## 3. 화면별 상세 레이아웃

### A. 홈

1. **헤더**: `홈` + 날짜. 우측에 알림/빠른 액션.
2. **오늘의 요약 3열**: 업무 작성 여부, 오늘 예약, 손님 반응. 각 카드에는 큰 숫자와 상태 색상/링크.
3. **월 목표 카드**: 전폭. 목표·누적·남은 금액, 골드 진행 막대와 달성률(예: 63%).
4. **3열 보조 카드**: 공지 / 연간 일정 / 최근 알림. 날짜 배지(42px 폭)와 작은 타임스탬프를 쓴다.

### B. 일일 운영 입력

1. 헤더: 날짜 이동 컨트롤, 임시저장 시각 pill, `삭제`·`엑셀 미리보기`·`저장` 액션.
2. 누락 항목이 있으면 전폭 `AlertBanner`를 헤더 바로 아래에 둔다.
3. 상단 **2열(360px : 나머지)**:
   - 좌측 `환경 · 근무 정보`: 날씨, 기온, 오픈/마감 근무 2×2 필드.
   - 우측 `채널별 매출`: 라벨-금액 입력 행. 미입력은 골드 워시.
4. 다음 행 **좌 360px / 우 나머지**: `메모 · 점검`과 `제품 생산 · 판매` 테이블.
5. 제품 테이블 컬럼 비율: `1.6fr / .7fr / .7fr / .7fr / 1fr / 1.1fr` (제품, 생산, 판매, 폐기, 판매가, 자동 매출). 하단 3열 잉크 KPI 카드.
6. 마지막에 엑셀 미리보기/원본 보존 상태를 별도 카드로 노출한다.

### C. 예약

1. 헤더: `예약` + 오늘/주간 건수, 날짜 이동, 검색, `신규 예약` CTA.
2. 본문 **2열**: 좌측 넓은 예약 타임라인/리스트, 우측 약 300px 신규 예약 폼.
3. 타임라인은 시간(좌), 손님·품목·상태(중앙), 액션(우)을 둔다. 당일 시간대는 굵은 글자 또는 색상으로 구분한다.
4. 폼은 고객 정보 → 픽업 시간 → 품목/수량 → 메모 → 저장 순서의 점진적 공개를 따른다.

### D. 손님 반응

1. 헤더: 최근 7일 건수와 확인 필요 건수, 기간 필터/검색.
2. 상단 `반응 입력` 카드: 원문 입력, 대·중·소 분류 선택, 확인 필요 토글, 저장 버튼.
3. 하단 `상세 기록` 테이블: 필터, 건수 메타, 5개 내외 레코드. 분류 pill과 확인 필요 상태를 함께 표현한다.

### E. 매출 분석: 기본 대시보드

1. 헤더: 연도 선택 + 엑셀 내보내기.
2. 상단 **4열 KPI**: 기간 매출, 전년 동기, 증감, 일정 영향 일수.
3. 중단 **2열**: 좌측 월 목표 막대 그래프, 우측 채널별 비중 도넛/리스트.
4. 하단 **3열**: 판매 상위 제품, 손실 점검 제품, 정리 필요 데이터.
5. 차트에서 올해는 골드, 비교년도는 베이지, 성공 수치는 초록으로 고정한다.

### F. 매출 분석: 작년 대비 상세

1. 기본 분석 탭 아래에 `상세 분석` 탭을 추가한다.
2. 필터 행: 날짜 범위/기간 단위 세그먼트(`일별` 활성), 일정 유형 chips.
3. 4열 KPI 뒤 전폭 **14일 쌍 막대 차트**(높이 150px). 날짜 라벨 아래, 일정이 있는 날짜에는 차트 위 dot + 라벨 강조.
4. 아래 전폭 표: `110px / 1fr / 130px / 130px / 90px / 200px` (날짜, 일정, 올해, 전년 동요일, 증감, 비고). 일정 유형별 행 틴트를 넣는다.
5. 보조 변형으로 월 목표 흐름 막대만 전폭 카드로 보여 주며, 막대 클릭 시 상세를 펼친다는 인터랙션을 제안한다.

### G. 단골손님

1. 헤더: 등록 단골·확인 대상 후보 숫자, 검색.
2. 좌측 넓은 `저장된 단골` 테이블, 우측 좁은 `확인 대상 후보` 카드.
3. 고객 행에는 이름/연락처/방문·구매 요약/태그/상세 액션을 둔다. 후보는 근거와 `단골 등록` CTA를 함께 둔다.

### H. 선결제 장부

1. 헤더: 활성 건수, 총 잔액, 신규 등록 CTA.
2. 상단 요약/잔액 카드와 고객 검색.
3. 본문 **좌 55–60% / 우 40–45%**: 좌측 거래 내역 테이블, 우측 고객/공동 선결제 상세.
4. 공동 선결제는 잔액/한도를 한 줄에, 참여자별 사용 상태를 하단에 표현한다.

## 4. 구현 시 보완할 점

- 원본의 1194px 고정 폭을 그대로 프로덕션에 사용하지 않는다. 위 반응형 규칙과 모바일용 표 변환을 적용한다.
- `#261e18`을 본문 전체에 과도하게 쓰지 말고, 장문 본문에는 `--color-text-secondary`를 사용해 대비를 완화한다.
- 골드 텍스트(`--color-primary-strong`)가 흰 배경에서 작은 크기로 쓰일 때는 대비를 재검증하고, 정보는 텍스트/아이콘으로 보강한다.
- 모든 정적 그래프는 실제 데이터 연결 시 범례, 툴팁, 스크린리더용 요약값을 제공한다.
- 원본의 hover/선택 상태는 제시되어 있지 않으므로 버튼·메뉴·표 행에 150–200ms의 opacity/background transition과 명확한 keyboard focus ring을 추가한다.
- 그리드 수치(210px, 360px, 14px 등)는 기준 폭의 설계 값이다. 컴포넌트에는 토큰/`minmax()`를 적용해 실제 데이터 길이와 번역 길이에 견디게 한다.
